ENDLESS ATLAS: OPEN DATA

The coordinates behind the Endless Atlas. 32,111 Magic cards, each positioned on six similarity maps, plus the cluster labels. Build whatever you want with it. Credit is nice.

atlas-data.json (12.1 MB) atlas-data.min.json.gz (2.7 MB)

What's new

v1.2 (2026-09-23). Reality Fracture (268 cards) is on the map. The new cards aren't tournament-legal until release on Oct 2, so format filters hide them until then. Positions of every pre-existing card are unchanged.

Load it in one line

import pandas as pd, json
df = pd.json_normalize(json.load(open("atlas-data.json"))["cards"])
# columns: oracle_id · name · color_identity · lenses.<lens>.x / .y

What's inside

KeyContents
metaVersion, date, license, attribution, and caveats.
cardsOne record per card: oracle_id (Scryfall), name, color_identity ("WUBRG" letters, empty = colorless), and lenses.<id>.x/.y, the card's position in [0,1] on each of the six maps.
clustersPer lens: label text, member count, anchor x/y, display color.

The six lenses

Notes & caveats

Positions are the atlas's true lens coordinates, not the deep-zoom spread layout. They were stored on a uint16 grid, so precision is about 1.5×10⁻⁵. Distances mean something within a neighborhood. Between distant islands, especially in the combo lens, they don't, so don't build anything that depends on them. No raw EDHREC data is included, only the final derived positions.
